# 商品研究助手

用多轮对话想清楚要买什么，再研究对应品类，把日常感受变成可搜索、可核验的商品条件。

## 复制即用

1. 打开[通用指令](通用指令.md)，复制全文到 GPT、DeepSeek 或淘宝内置 AI 的聊天框。
2. 加一句「我想买……」。例如「我想买夏天通勤穿、出汗后不容易黏身的衣服」。
3. 回答影响筛选的几个问题。AI 会按需继续追问，同时研究同类产品的材料、结构或规格，并用日常语言说明取舍。

如果当前 AI 能读取目标购物平台的商品详情，就让它直接搜索并核对具体规格。否则，它会生成一段不超过 500 字的搜索指令。把这段贴到淘宝内置 AI 或目标平台的购物 AI。你也可以把候选结果贴回原对话，让研究助手判断是否符合需求、调整搜索条件。

研究能查到多少取决于 AI 的检索能力。淘宝内置 AI 能否完整执行多轮追问、研究和搜索，尚未实测。

## 在 Codex 中使用

将 [`skills/product-research`](skills/product-research) 放到项目的 `.agents/skills/` 目录下，在 Codex 中输入：

> 使用 $product-research。我想买……

技能与通用指令采用同一份正文。插件清单保存在 [`plugin.json`](plugin.json) 和 [`.codex-plugin/plugin.json`](.codex-plugin/plugin.json)。
